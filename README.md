# Demand Atlas

**차트에서 장바구니까지 — K-pop 굿즈 글로벌 물량 배분 도구**

아티스트와 총 발주 수량을 넣으면, 71개국 Spotify 차트에서 계산한 시장별 침투도에
굿즈 실거래 권역 비중을 곱해 지역별 배분안을 냅니다.
총 수량은 사용자가 정하고, 도구는 나누기만 합니다.

| | |
|---|---|
| 도구 | [`index.html`](index.html) |
| 리서치 | [`research.html`](research.html) |
| 원천 데이터 | [Spotify Charts · Kaggle](https://www.kaggle.com/datasets/gonzalopezgil/spotify-charts-daily-updated) (CC BY-SA 4.0) · 25,148,197행 |
| 가공 결과 | 아티스트×국가×일자 팩트 614,789행 · 71개국 · 2021-10-21 ~ 2026-11-05 |
| 코호트 | K-pop 107팀 (소속사 라벨 기반 추출 + 수동 보정) |

두 페이지 모두 **의존성 없는 단일 HTML**입니다. 빌드 단계도 서버도 없고,
파일을 그대로 열거나 정적 호스팅에 올리면 동작합니다.

## 이 도구가 푸는 문제

굿즈 발주에서 제일 어려운 건 총 수량이 아니라 **배분**입니다.
어느 나라에 몇 개를 보낼지는 보통 작년 실적과 감으로 정하는데,
신규 아티스트거나 신규 시장이면 참고할 실적 자체가 없습니다.

공개된 굿즈 판매 데이터는 존재하지 않습니다. 그래서 대리 지표를 씁니다 —
다만 **대리 지표 하나로는 안 됩니다.**

### 왜 2개 층인가

차트 점유율만으로 물량을 나누면 **북미에 1%를 배정하는 결과**가 나옵니다.

| | 북미 | 동남아 |
|---|---|---|
| Top 200 차트 점유율 | 1.04% | 6.15% |
| 실제 굿즈 리세일 거래 비중 | **51.7%** | (아시아 19.1%) |

차트는 **듣는 사람**을 세고, 굿즈는 **사는 사람**이 필요합니다.
게다가 차트는 나라마다 똑같이 200칸으로 잘려 있어서, 인구 5천만 국가와 3억 국가가
같은 분모를 갖습니다. 점유율은 시장 규모가 아닙니다.

검증 중 실제로 나온 사례: ATEEZ의 유럽 침투도에서 **독일이 꼴찌(0.08%)**로 나왔지만,
리세일 실거래에서 독일은 ATEEZ의 **1위 시장**입니다.

그래서 배분을 둘로 나눴습니다.

- **1층 · 침투율** — 차트에서 계산. 권역 **안에서** 어느 나라에 수요가 몰리는지만 판단
- **2층 · 권역 가중** — 차트가 아니라 실제 리세일 거래 비중(외부 인용값). 권역 **사이** 배분을 결정

`research.html`은 이 설계의 근거입니다. 70개국 60개월 점유율 추이를 집계해,
차트 점유율과 구매력이 어떻게 어긋나는지 보여 줍니다.

## 산출 로직

```
침투율 = 차트 체류일 비중 × 순위 가중 × 최근성 가중
```

- **컴백 윈도우**: `peak_date − 7일 ~ peak_date + 53일` (60일). K-pop 아티스트는
  컴백 전후에만 폭넓게 차트에 오르므로, 전 기간 평균을 쓰면 시장이 과소평가됩니다
- **표본 가드**: 분석 윈도우 안의 차트 체류일이 **30일 미만**인 권역은 자동 배분하지
  않고 "표본 부족 · 수동"으로 넘깁니다 (전 기간 행 수가 아니라 **윈도우 안의 근거**로 판단)
- **최대 잔여 배분법**으로 반올림해, 배분 합계가 입력 총량과 **항상 정확히 일치**합니다
- **SKU 환산**: 멤버별 상품은 멤버 수로 나눠 1종당 수량을 냅니다 (멤버 수는 UI에서 수정 가능)

권역 가중 기본값은 외부 입력이며 UI에서 직접 고칠 수 있습니다.
**세 권역만 출처가 있고, 나머지는 잔여분을 나눈 추정값입니다.**

| 권역 | 비중 | 근거 |
|---|---|---|
| 북미 | 51.7 | [번개장터 2025 글로벌 K-POP 트렌드 리포트](https://www.venturesquare.net/1035966/) 보도 수치 |
| 유럽 | 19.4 | 〃 |
| 아시아 | 19.1 | 〃 |
| 오세아니아 | 3.4 | **자체 추정** — 위 세 권역을 뺀 잔여 9.8%를 나눈 값 |
| 남미 | 3.4 | **자체 추정** |
| 중동·기타 | 2.9 | **자체 추정** |
| 아프리카 | 0.1 | **자체 추정** |

보도된 리포트에는 북미·유럽·아시아 세 권역의 비중만 공개돼 있습니다.
나머지 네 권역의 9.8%를 어떻게 쪼개는지는 **근거 없는 가정**이므로,
해당 권역의 배분 결과는 그대로 쓰지 말고 실제 운영 데이터로 교체해야 합니다.

## 데이터 파이프라인

원본 3.07GB를 그대로 다룰 수 없어서 단계마다 줄여 나갑니다.
전체 과정은 [`docs/PIPELINE.md`](docs/PIPELINE.md)에 있습니다.

```
charts_albums_weekly.csv  ──[label 컬럼 매칭]──>  K-pop 아티스트 93팀
                                                      │
                          수동 추가 4팀 + 라벨 확장 13팀 − 비한국 3팀
                                                      ▼
                                              코호트 107팀 (URI)
                                                      │
charts_artists_daily.csv  ──[URI 필터]──────────────> 팩트 614,789행
  25,148,197행 / 3.07GB                                 │
                                          ┌─────────────┴─────────────┐
                                          ▼                           ▼
                               SQLite + 인덱스 3개          국가×월 점유율 집계
                                          │                           │
                                   tool_data.json            share_data.json
                                   (24팀, peak≥15)           (70개국 × 60개월)
```

- 3GB 파일 전체 스캔이 I/O 타임아웃에 걸려서, `dd` 바이트 레인지로 4등분한 뒤
  gzip으로 압축했습니다 (628MB). 청크가 정확히 맞물려서 이어 붙이면 원본과
  바이트 단위로 동일합니다 — 25,148,198줄로 검증
- SQLite 인덱스 3개(`uri+date`, `uri+country`, `country+date`)로 조회를 **2.58s → 0.26s**
- parquet을 쓰려 했으나 pyarrow·fastparquet·duckdb·polars 모두 설치 불가 환경이라 SQLite로 대체

## 빌드와 검사

```bash
python3 src/mkshare.py      # share_data.json      -> data/share_page_data.json
python3 src/build.py        # 템플릿 + 데이터      -> index.html, research.html

node test/qa_tool.js        # 도구 동작 52개 검사
node test/qa_research.js    # 리서치 동작 68개 검사
node test/qa_map.js         # 지도 렌더 3개 경로(정상 / 폴백 / 실패) 검사
```

테스트는 Playwright가 필요합니다 (`npm i playwright`).
`qa_map.js`는 지도 라이브러리를 스텁으로 갈아끼워, 배색이 적용되지 않았을 때
**회색 지도를 그대로 내보내지 않고 안내 문구로 폴백하는지**까지 확인합니다.

배색은 색각 이상 ΔE·명도 밴드·대비 검증을 통과한 조합만 씁니다.
순차 램프는 단일 색상 명도 단조, 발산 축은 두 색상 + 중립 중점입니다.

## 이 수치로 말할 수 있는 것과 없는 것

**말할 수 있는 것**

- 국가 간 비교. 동일한 107팀 코호트를 70개국에 똑같이 적용했고, 분모는 모든 국가가
  매일 200칸으로 같습니다
- 권역 안에서의 상대적 수요 쏠림

**말할 수 없는 것**

- **절대 수요.** 굿즈 판매 데이터는 공개된 것이 없습니다. 총 발주 수량은 사용자 입력입니다
- **시장 규모.** 200칸은 인구와 무관하게 모든 국가에 똑같이 주어집니다
- **큰 시장 안에서의 국가 순서.** 미국과 캐나다처럼 차트 칸 수는 비슷하지만 규모가
  크게 다른 쌍은 뒤집힙니다. 도구에서 권역 단위는 "확정", 국가 단위는 "참고 분배"로 구분해 표시합니다
- **전세계 시계열 추세.** 코호트가 고정이라 기간 중 데뷔한 팀(KATSEYE, TWS 등)이
  구조적으로 빠집니다. 하락폭이 실제보다 과장됩니다
- **Top 200 밖.** 201위 이하는 0으로 집계됩니다. 팬덤이 두텁지만 스트리밍이 얇은
  중소 그룹의 시장은 보이지 않습니다
- **한국 내 실제 소비.** Spotify는 국내 점유율이 낮아, 한국 수치는 국내 Spotify 이용자 기준입니다
